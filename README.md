# AdminPanel Automation Framework

## Project Description

This project is a Selenium Java Automation Framework built using the Page Object Model (POM) to automate a demo web admin dashboard application. It covers end-to-end UI testing for forms, tables, alerts, dynamic elements, and frames.

## Features

* Form Automation (text fields, dropdowns, checkboxes, radio buttons)
* Table Operations (sorting, pagination, data validation)
* Alerts Handling (alert, confirm, prompt)
* Dynamic Elements Handling (add/remove, enable/disable, redirects)
* Frame & iFrame Handling
* FluentWait for dynamic synchronization
* Screenshot on Failure using TestNG Listener
* Extent Reports for execution results
* Configurable execution via config.properties

## Tech Stack

* Java
* Selenium WebDriver
* TestNG
* Maven
* WebDriverManager
* ExtentReports

## Test Modules

* Form Interactions
* Table Operations
* Alerts and Dialogs
* Dynamic Elements
* Frames Handling

## Reports

Execution reports are generated in the `/reports` folder using ExtentReports.

## Screenshots

Screenshots are captured automatically on test failure and stored in `/screenshots`.
